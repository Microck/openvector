# Unreleased

OpenVector is available as private source. No application version has been published.

- Native desktop app, CLI, and Node-API library share one Rust tracing engine.
- Raster input, palette and background editing, batch conversion, profiles, and
  vector/bitmap export are available.
- Windows scrollbar paging continues after held-button capture transfer and stops
  at the pointer, matching the observed native workflow.
- Failed Open intentionally preserves the previous image and its export state.

See [verification](docs/verification.md) for tested scope and remaining limits.
