# OpenVector parity matrix

Completion tracker for the Rust + GPUI port. A row is done only when its
evidence column names a passing check that compares against native captures
(or a recorded stable property for proven nondeterminism). "JS ref" means the
behavior exists and is verified in the JavaScript reference in `src/`, which
the Rust port must replace. Passing the fixture suite alone is not full parity.

Status: `todo`, `port` (in progress), `rust` (Rust passes the differential
test), `gap` (known mismatch, see notes), `partial` (GUI checks expose failures), `nondet` (stable properties tested).

The [classification lifetime correction](../evidence/full-parity-program-20261022/classification-measurement-rootcause/summary.json) passes all 24 strict fresh-capture cases and 84 tests across eight relevant suites. Actual document smoke matches all 149784 candidate indices, 48 palette channels and RNG9599 after shrinking replacement. This closes that intermediate-state mismatch, not the remaining platform and application gaps.

Reference capture resumed after [explicitly authorized namespace recovery](../evidence/native-namespace-recovery-20261021/verification.json).
The prior [stale-Back probe](../evidence/native-stale-back-20261021/report.json)
created `HKCU\Software\Vector Magic\Ambivalence Native Clean Reference`
in the 32-bit registry view outside its then-authorized staging writes.
Its contents were backed up and verified losslessly before removing only that
probe-owned namespace. All 43 installation files, the recorder and every other
registry key/value remained unchanged. New captures have one execution owner
and must restore the full protected-state baseline after owned-namespace cleanup.
The old Back result remains inadmissible until its checkbox precondition is
corrected and asserted. No executable, license or headless guard is bypassed.
