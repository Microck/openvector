The defined-storage observer resolves the first label producer. Storage resize
at 0x481950 preserves elements when dimensions match and otherwise allocates
without initialization. Grid resize at 0x4840d0 clears metadata without filling
labels. The producer at 0x4891a0 fills the entire grid with pixel identifiers;
its return at 0x4aab3b precedes subsequent progress callbacks. Region count alone
cannot establish whether labels exist. Hardware execute observation tracks these
actual boundaries without changing native instructions. The serializer omits
element bytes before initialization and fails if initialized storage unexpectedly
changes. It preserves old initialized labels during a same-size rerun.
